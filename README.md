# Quantum Circuit Simulator
A quantum circuit simulator built from scratch in Python.

## Status
In development

This project is being developed while learning the fundamentals of quantum computing, including quantum states, quantum gates, measurement, and quantum circuits.

## Goals

- Understand the fundamentals of quantum computing
- Represent quantum states computationally
- Implement basic quantum gates
- Implement quantum measurement
- Support multi-qubit circuits
- Explore fundamental quantum algorithms

## Tech Stack

- Python
- NumPy
